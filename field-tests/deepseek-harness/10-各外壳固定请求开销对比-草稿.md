## 列口径（每一列只用一种）

| 列 | 口径 |
|---|---|
| `body_len` | 抓包 JSON 的 `body_len` = 原始 HTTP 请求体字节数 |
| `system_chars` | **字符数**（非 token）。算法见各行 `system_method`。**在内部原件上统计，脚本输出已入库**（`recalc_compare.py` → `numbers.json` / `recalc_compare.out.txt`）。`body_len` 为抓包时原始 HTTP 体字节。†OpenCode：归档前已做路径打码，8697 基于该版本；LOG 曾记 8799，无更早原件可复核（见 `opencode-system-chars-search.txt`）。 |
| `tools_n` / `tools_json_compact_chars` | 同一脚本：`json.dumps(tools, ensure_ascii=False, separators=(',',':'))` 的长度；**无 `tools` 字段**则记「无字段」，不写成 `[]` 的 2 |
| `请求数` | 该次抓包目录下 `req-*.json` 个数。**仅此配置：本地假服务 + 单次 say hi，n=1**，不能当成工具固定请求数 |

任务对齐用户说 **「say hi」**；表中数字取**正式包**（带工具定义或主回答的那一次，一般为 `req-01`）。

## 草稿结论（不超出证据）
- 同样一句「say hi」，正式包 `body_len` 跨度 11,046–54,923 字节（本地假服务、n=1）。
- dsh 真默认因专用字段最大；加隐私补丁后body_len 为 22,680，与 OpenCode 的 22,803 接近（n=1）。
- Claude Code 工具紧凑 JSON 最长（29,512）；Aider 正式包最小且无 tools 字段，system 字符串最长（9,644）。
- **请求数**只描述本次配置下抓到的包数，不是产品固定值。
- 不能据此比较真·DeepSeek 账单（无 usage、无真 key）。
