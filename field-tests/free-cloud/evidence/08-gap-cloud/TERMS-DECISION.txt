# Terms / privacy / AUP review before any SSH (2026-11-09 America/New_York)

## What we found
1. Product page https://gap.geta.team/free-vm (HTTP 200):
   - "No account or card to start."
   - FAQ: "Do I need to sign up? No. An account and verified email are required only if you choose to claim the VM."
   - "The first authenticated session creates your VM."
   - Anonymous outbound limited to approved package registries; arbitrary internet blocked.
2. Dedicated legal paths on gap.geta.team (/terms /privacy /aup /legal …): HTTP 410 Gone.
3. Parent brand https://geta.team/terms and /privacy (HTTP 200): cover Geta.Team AI Employees / subscriptions (BYOA), not Free MicroVM specifically. Archived in internal-archive/08-gap-cloud/pages/.
4. https://elest.io/terms (HTTP 200): Elestio managed DevOps ToS; Free VM SSH host is on *.vm.elestio.app. No Free-MicroVM-specific anonymous clause found in our skim.
5. No dedicated AUP URL found on geta.team (404) or gap.geta.team (410). Closest operational text: free-vm "Safety" section + docs "Customer and fleet suspension".

## Decision
Product page explicitly allows anonymous, no-account start for the one-hour Free MicroVM. Formal GAP-specific ToS/Privacy/AUP documents were not published at the probed URLs (410/404). Parent ToS does not clearly forbid the advertised anonymous free-vm path.
Proceeding to attempt exactly ONE ssh session as documented, with a fresh throwaway key, read-only config commands only — stopping if registration is demanded or the network blocks.
