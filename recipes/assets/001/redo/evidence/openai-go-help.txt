# What is ChatGPT Go?
ChatGPT Go is a low-cost subscription plan with expanded access to ChatGPT features.
Note: ChatGPT Go is now available in all ChatGPT supported countries.
# What's included
Everything included in the Free plan, and:
- Expanded access to ChatGPT tools: Get higher usage limits for eligible features than on the Free plan.
- Extended access to image generation: Create more images for work or play.
- Extended access to file uploads: Analyze and work with more documents, spreadsheets, and other files.
# Availability
ChatGPT Go is available in all countries ChatGPT is supported in. All purchases are in USD - we offer a local currency billing in a limited set of countries (see: Multi-currency billing). Subscription prices can be found in the ChatGPT pricing page. Note that we may adjust pricing over time as we learn from early use and gather feedback. Subscriptions are billed automatically monthly, and can be canceled anytime.
## Is there an annual plan available?
Currently, we do not support annual billing or the option to pay for multiple months in advance for ChatGPT Go, Plus, or Pro subscriptions.
