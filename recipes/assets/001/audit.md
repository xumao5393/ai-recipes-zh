# 第001期：重新演示的验收记录

## 不是什么
这是同一代理连续做三档的教学演示，不是 GPT/Claude/Gemini 三款应用对比，不是独立隔离模型试验。未运行真实 MCP 客户端/服务器，未测试 Skill 自动加载，也未对 Harness 做开关消融。不能说“Skill 使准确率提高了多少”。

## 固定材料与顺序
1. 先只读取 task_prompt.txt；尚未读旧价格证据或新网页，保存 level1.md（记忆答案）。模型已有训练与父对话背景，不能说完全无先验。
2. Level2 只读三个官方价格页并保存答案，未读本期 Skill。没有用搜索去补价格，查不到就留空。
3. 阅读并修订 Skill，再按检查单复读三页，并补查官方帮助与历史公告。搜索结果不是定价证据，随后 WebFetch 打开核对。
4. 用保存的官方返回文本建立12行×5字段参考表，再逐格人工评分。执行者和评分者相同，非盲审。

## 评分规则（五字段，60格）
- 字段：产品、当前档位/子档、美元月付与明确周期、功能一句话、当前价格来源。
- correct：和本次官方快照一致；不是证明真实账户结账价格或付费体验。
- wrong：明确与快照冲突。
- missing：缺行、缺子档、没拿到现价，或没有本次访问且能支持当前价格的来源。
- fabricated_source：伪造来源/引用；本次没有发现。链接未访问但已坦承不等于伪造，判 missing。
- Go 当前美元价无法从当前页面核定，其金额及其当前价格来源均判 missing，连第三档也不豁免。1月公告$8仅为历史参考。
- 名称允许清楚的同义别名（如Claude Max 5x），但新子档缺失不补猜。L1泛称Pro映射Pro200，L1泛称Ultra映射Ultra20x；L2泛称Pro也只映射Pro200一次，其他子档算漏行。
- 最低主表不要求报价原文逐字引述才能判来源 correct；但必须真的取到支持金额的官方文本。引用原文是第三档新增可审计性，不是为了打分临时加门槛。
- 月付表格之外明确写出的年付条件也纳入核对。未测体验不计成虚构。
