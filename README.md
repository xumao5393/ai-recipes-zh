# ai-recipes-zh：给非程序员的 AI 工具配方

每一期解决一个具体问题：用哪些免费工具、按什么步骤、花了多少钱和时间、会在哪里卡住。

## 规则

- **每一步都实际跑过。** 每期注明实测日期和环境，日志、输出文件、截图放在 `recipes/assets/` 里，可以自己复现。
- 没测过的内容不写进步骤；测不了的情况会明确写"未测试"。
- 只用免费工具，不需要付费账号。
- 写清楚"什么情况不值得做"。
