# ai-recipes-zh：AI 实测说明书（中文）

**不给你列工具清单，只告诉你：为了办成一件事，用哪几个 AI、按什么顺序、花多少钱。每期写明实测范围，附原始输出与证据；示意图和界面截图分开标注。**

写给不写代码、但每个月为好几个 AI 订阅付钱的人：看不懂 Agent、MCP、Skill 这些词，也不知道钱花得值不值。

## 规则：每一步都实测过

- **只写亲手跑过的东西。** 每期都写明实测日期、环境、能确认的模型信息（不能确认就说明），原始输出、日志和截图都放在 `recipes/assets/<期号>/` 里，你可以自己复现。
- **AI 的回答要核对，无法核定的价不拿来推荐购买。** 结论里的每个数字都和官方页面对过；AI 编错的地方直接标出来，不替它遮掩。
- **跑失败也照实写。** 失败的记录同样公开，并说明卡在哪一步。
- **别人的测评只当参考。** 引用网上测评时注明出处，和我们自己测的结果分开写。
- **没测的不冒充测过。** 这一期没测到的工具会直接写"本期未测"，放到后面的期数去测。
